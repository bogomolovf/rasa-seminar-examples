# 01_hello_bot — Минимальный бот на RASA

## Педагогическая цель

Показать скелет RASA-проекта в его простейшем виде: как текст пользователя превращается в intent, как intent сопоставляется с ответом, как всё это описывается в файлах.

## Новые концепты (первый пример — всё с нуля)

| Концепт | Файл | Что показывает |
|---|---|---|
| Intent | `data/nlu.yml` | Набор обучающих фраз → метка намерения |
| Utterance | `domain.yml` → `responses` | Шаблонный ответ бота |
| Rule | `data/rules.yml` | Детерминированное правило intent → action |
| Story | `data/stories.yml` | Пример многошагового диалога |
| Pipeline | `config.yml` | Цепочка NLU-компонентов |
| Policy | `config.yml` | Алгоритм выбора следующего действия |

## Команды для запуска

```bash
# 1. Перейти в директорию примера
cd examples/01_hello_bot

# 2. Обучить модель (займёт 1–3 минуты)
rasa train

# 3. Запустить чат в терминале
rasa shell

# 4. (Опционально) Проверить NLU отдельно
rasa shell nlu
```

> **Требования:** conda activate rasa-seminar перед запуском.

## Структура файлов

```
01_hello_bot/
├── data/
│   ├── nlu.yml        # обучающие примеры для интентов
│   ├── stories.yml    # многошаговые сценарии диалога
│   └── rules.yml      # детерминированные правила
├── domain.yml         # словарь бота: intents, responses, actions
├── config.yml         # pipeline NLU и политики DM
├── endpoints.yml      # адрес action server (не используется в этом примере)
└── README.md
```

## Идеи для самостоятельного задания

1. Добавить intent `bot_challenge` («Ты бот?», «Ты человек?») с соответствующим ответом — убрать его из `out_of_scope`.
2. Добавить несколько вариантов ответа в `utter_greet` и убедиться, что бот отвечает случайным образом.
3. Снизить порог `FallbackClassifier` до 0.4 — как изменится поведение бота?
4. Написать story с 3+ шагами (greet → affirm → goodbye) и проверить, что модель её воспроизводит.
